# Snake Game

A modern and responsive Snake Game built using HTML, CSS, and Vanilla JavaScript. Control the snake, collect food, increase your score, and avoid collisions with walls and your own body. The game includes difficulty levels, high-score tracking, theme switching, sound controls, and mobile support.

---

## Features

### Gameplay
- Classic Snake Game mechanics
- Smooth snake movement
- Food generation at random locations
- Snake grows after eating food
- Collision detection
- Game Over screen
- Restart functionality

### Score System
- Real-time score tracking
- High score tracking
- High score saved using Local Storage

### Difficulty Levels
- Easy
- Medium
- Hard

### Controls
- Arrow Keys support
- WASD support
- Mobile touch controls
- Pause and Resume functionality

### Theme Support
- Light Theme
- Dark Theme
- Theme preference saved in Local Storage

### Sound Features
- Food collection sound
- Button click sound
- Game Over sound
- Sound On/Off toggle

### Responsive Design
- Desktop support
- Tablet support
- Mobile-friendly interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

No external frameworks or libraries are required.
